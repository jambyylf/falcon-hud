# FalconHUD

Claude Code қолданысын, лимиттерді, фондағы агенттерді және компьютер күйін
нақты уақытта көрсететін қалқымалы виджет (Windows + macOS).

---

## Іске қосу

```bash
npm install     # бір рет қана
npm start
```

**Басқару:** тақырыптан ұстап сүйреу · екі рет басу — шағын/толық режим ·
`Ctrl+Alt+H` — көрсету/жасыру · трей иконкасында қалған баптаулар (демо режим де сонда).

---

## .exe / .dmg жинау

```bash
npm run build:win     # Windows орнатушысы → dist/
npm run build:mac     # macOS .dmg (тек Mac-та жиналады)
```

---

## Бағаны өзгерту

Құн `pricing.json` файлынан есептеледі. Anthropic бағаны өзгертсе, сол файлдағы
сандарды түзетіп, виджетті қайта қосу жеткілікті — кодқа тиюдің қажеті жоқ.

| Өріс | Мағынасы |
|---|---|
| `input` / `output` | 1 млн токеннің бағасы ($) |
| `cache_write_5m` / `cache_write_1h` | кэш жазу (әдетте input × 1.25 және × 2) |
| `cache_read` | кэштен оқу (әдетте input × 0.1) |

Тізімде жоқ жаңа модель шықса — `fallback` бөліміндегі баға қолданылады.
Орнатылған нұсқада файл `resources\pricing.json` ішінде жатады.

## Қай файл не істейді

| Файл | Не істейді |
|---|---|
| `src/main.js` | Барлық дерек осында жиналып, интерфейске жіберіледі |
| `src/modules/usage-parser.js` | `.jsonl` транскрипттерден токен санайды (+ формат өзгерсе ескертеді) |
| `src/modules/agents.js` | Белсенді сессиялар мен subagent-терді табады |
| `src/modules/limits.js` | Жазылым лимиттерін оқиды (тек оқу, токен ешқайда жіберілмейді) |
| `src/modules/system.js` | CPU / GPU / RAM / диск / желі |
| `src/modules/window.js` | Терезе, трей, ыстық перне, хабарламалар |
| `src/renderer/` | Көрінісі: `index.html` · `style.css` · `app.js` |

FalconHUD жеке дерегін жоба папкасынан **тыс** сақтайды:
`~/.claude/falconhud/history.json` (күнделікті жиынтық) және `parser-issues.log`.
