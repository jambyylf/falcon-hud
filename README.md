# FalconHUD

Claude Code пен Codex қолданысын, лимиттерді, фондағы агенттерді және компьютер
күйін нақты уақытта көрсететін қалқымалы виджет (Windows + macOS).

---

## Дерек көздері

FalconHUD екі құралдың транскрипттерін оқиды. Кемінде біреуі болса — жұмыс істейді:

| Құрал | Қайдан оқиды | Не береді |
|-------|--------------|-----------|
| Claude Code | `~/.claude/projects/` | токен, шығын, сессия күйі, агенттер, лимит (желіден) |
| Codex | `~/.codex/sessions/` | токен, шығын, жоба саны, 5 сағаттық және апталық лимит |

Екеуінің саны бір есепке қосылады, ал лимиттері бөлек жол болып тұрады
(«Codex · апталық» деген сияқты). Қай құрал табылғанын **Баптау → Дерек көздері**
бөлімінен көруге болады. Ешқайсысы табылмаса — виджеттің басында сары ескерту шығады.

> Codex-тің лимиті желіден емес, транскрипттен оқылады. Сондықтан ол Codex-пен
> соңғы рет жұмыс істеген сәттегі мән. Терезенің мерзімі өтіп кетсе, ескі санды
> көрсетпей, сол жолды мүлдем жасырамыз.

> **Басқаға таратқанда:** [INSTALL.md](INSTALL.md) — қабылдаушыға арналған толық
> нұсқаулық (орнату, SmartScreen ескертуі, Telegram қосу, ақаулар). Бұл README
> әзірлеушіге арналған, оны жіберудің қажеті жоқ.

## Іске қосу

**Күнделікті қолдану үшін — орнатып қойған дұрыс.** Сонда виджет терминалға
тәуелді болмайды әрі компьютер қосылғанда өзі іске қосылады (Telegram хабарлары
да тек виджет жұмыс істеп тұрғанда келеді):

```bash
npm run build:win                       # орнатушы жасау → dist/
dist/"FalconHUD Setup 1.0.1.exe"        # орнату
```

Орнатқан соң автоқосылуды қосу — трейден «Компьютер қосылғанда іске қосу»,
немесе командадан:

```bash
"%LOCALAPPDATA%\Programs\FalconHUD\FalconHUD.exe" --enable-autostart
```

**Кодты өзгертіп сынау үшін** (орнатудың қажеті жоқ):

```bash
npm install     # бір рет қана
npm start
```

**Басқару:** тақырыптан ұстап сүйреу · екі рет басу — шағын/толық режим ·
тақырыптағы **⚙** — баптау ·
`Ctrl+Alt+H` — көрсету/жасыру · трей иконкасында қалған баптаулар (демо режим де сонда).

**Сессия күйлері:** 🟢 жұмыста · 🟣 агент жүруде · 🟡 сізді күтуде / жауап күтуде ·
🔴 рұқсат күтуде. Сізді күтіп тұрғандары тізімнің басында тұрады, ал дайын болған сәтте
жүйелік хабарлама келеді (трейден өшіруге болады).

**Жоба бөлшегі:** «Жобалар» тізімінде кез келген жолды бассаңыз, сол жобаның бүгінгі
модель бөлінісі, сессия күйі және соңғы 30 күндегі динамикасы ашылады.

**Лимит пайызы — ЖҰМСАЛҒАНЫ** (қалғаны емес): сан, жолақ, сақина және түс бәрі бір
бағытта өседі. 50%-ға дейін жасыл · 50–80% сары · 80%-дан жоғары қызыл.

## Лимит қашан бітеді (болжам)

Әр лимиттің астында «осы қарқынмен жүрсең не болады» деген жауап тұрады:

- **жетеді** — терезе жаңарғанша лимит бітпейді, тыныш жұмыс істей беруге болады;
- **1к10сағ соң бітеді** — жаңаруға жетпейді, сары түспен жазылады;
- **13м соң бітеді (14:33)** — 30 минуттан аз қалса қызыл болады, әрі нақты сағаты
  қосылады (сағат тек 12 сағаттан жақын болжамға қосылады — әйтпесе қай күні екені
  түсініксіз болар еді).

Шағын режимде де көрінеді: сақинаның астындағы жазу әдетте терезенің жаңару
уақытын көрсетеді, ал лимит жетпейтін болса — оның орнына **⚠ 1к10сағ** тұрады.
Telegram-дағы `/status` жауабына да қосылады.

**Қалай есептеледі.** Виджет әр лимиттің пайызын уақытымен бірге жазып отырады
(`~/.claude/falconhud/limit-trend.json` — ішінде тек пайыз бен уақыт, басқа ештеңе жоқ).
Соңғы 90 минуттың нүктелеріне ең кіші квадраттар әдісімен түзу сызық жүргізіледі —
бір-екі кездейсоқ секіріс болжамды бұзбасын деп. Сол қарқынмен 100%-ға қашан
жететіні есептеледі. Терезе жаңарғанда пайыз түсіп кетеді — ондайда ескі нүктелер
тасталып, санақ нөлден басталады.

Дерек аз болса (үш нүктеден кем, не 8 минуттан қысқа) болжам мүлдем көрсетілмейді:
жалған сан көрсеткеннен гөрі үндемеген дұрыс. Codex лимиті транскрипттен оқылатын
болғандықтан, Codex-пен жұмыс істемеген кезде оның болжамы да тұрып қалады.

## Баптау панелі

Виджеттің тақырыбындағы **⚙** түймесін басыңыз — баптау **бөлек терезе емес**,
сол виджеттің өз ішінен жанынан сырғып шығады. Жабу үшін **‹** түймесі немесе
`Esc`. Шағын режимде тұрсаңыз, панель ашылғанда виджет уақытша толық режимге
ауысады да, жапқанда қайта шағын болады.
(Трейден де, `FalconHUD.exe --settings` командасынан да ашылады.) Мұнда бәрі бар:
Telegram, хабарламалар, ескерту шегі, терезе және баға файлы. Ешқандай файл
өңдеудің қажеті жоқ.

### Telegram-ға хабар (телефонға)

Компьютер басында отырмағанда да білу үшін. Бір рет баптайсыз:

1. Telegram-нан **@BotFather**-ды тауып, `/newbot` деп жазыңыз → ол **токен** береді.
2. Баптау панеліндегі өріске токенді қойып, **«Токенді сақтау»** дейсіз.
3. Жаңа ботыңызға Telegram-нан `/start` деп жазыңыз.
4. **«Сынақ хабары»** түймесін басасыз — телефонға хабар келуі керек.

**Не келеді:** сессия сізді күте бастағанда · лимит шектен асқанда · дерек
оқылмай қалғанда. Әрқайсысын баптау терезесінен бөлек өшіруге болады.

Телефоннан ботқа **`/status`** деп жазсаңыз — қазіргі жағдай келеді: күтудегі
сессиялар, лимиттер, бүгінгі токен мен құн.

Бір сессия 5 минутта бір реттен жиі хабарламайды, сондықтан 10+ сессия қатар
жүрсе де телефон тынымсыз дыбыстамайды.

> ⚠️ `botToken` — құпия. Ол `~/.claude/falconhud/telegram.json` файлында, жоба
> папкасынан **тыс** жатыр, сондықтан git-ке ешқашан түспейді. Логқа да,
> баптау терезесіне де жазылмайды — онда тек бот аты мен күйі көрінеді.

## Бағаны өзгерту

Құн `pricing.json` файлынан есептеледі. Anthropic бағаны өзгертсе, сол файлдағы
сандарды түзетіп, виджетті қайта қосу жеткілікті — кодқа тиюдің қажеті жоқ.

| Өріс | Мағынасы |
|---|---|
| `input` / `output` | 1 млн токеннің бағасы ($) |
| `cache_write_5m` / `cache_write_1h` | кэш жазу (әдетте input × 1.25 және × 2) |
| `cache_read` | кэштен оқу (әдетте input × 0.1) |

Тізімде жоқ жаңа модель шықса — `fallback` бөліміндегі баға қолданылады.
Орнатылған нұсқада файл `resources\pricing.json` ішінде жатады.

## Қай файл не істейді

| Файл | Не істейді |
|---|---|
| `src/main.js` | Барлық дерек осында жиналып, интерфейске жіберіледі |
| `src/modules/usage-parser.js` | `.jsonl` транскрипттерден токен санайды (+ формат өзгерсе ескертеді) |
| `src/modules/agents.js` | Белсенді сессиялар мен subagent-терді табады |
| `src/modules/limits.js` | Жазылым лимиттерін оқиды (тек оқу, токен ешқайда жіберілмейді) |
| `src/modules/system.js` | CPU / GPU / RAM / диск / желі |
| `src/modules/window.js` | Терезе, трей, ыстық перне, хабарламалар |
| `src/modules/telegram.js` | Telegram-ға хабар жіберу (токен ешқайда шықпайды) |
| `src/modules/forecast.js` | Лимит қашан бітетінін болжау |
| `src/renderer/panel.js` · `settings.css` | Баптау панелі (тақырыптағы ⚙ түймесі) |
| `src/renderer/` | Көрінісі: `index.html` · `style.css` · `app.js` |

FalconHUD жеке дерегін жоба папкасынан **тыс** сақтайды:
`~/.claude/falconhud/history.json` (күнделікті жиынтық) және `parser-issues.log`.
